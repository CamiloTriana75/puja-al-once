# Cómo jugar a Subasta Puja el Once

## Crear o encontrar una sala

1. Escribe el nombre con el que aparecerás en la partida.
2. Crea una sala privada y comparte su código, o elige **Pública · probar** para aparecer en el vestuario abierto.
3. Para entrar a una sala pública, elige una del listado. También puedes escribir el código de una invitación.
4. Cuando haya al menos dos jugadores, todos pulsan **Listo** para comenzar. La versión inicial admite de 2 a 4 personas.

Las salas públicas solo aparecen mientras esperan y tienen sitio. El listado no muestra los nombres de quienes están dentro. Una sala puede llenarse o empezar justo al entrar; en ese caso actualiza el listado y elige otra.

## Durante la partida

- Cada participante arma una plantilla de once posiciones: portero, defensas, centrocampistas y delanteros.
- Cada jugador comienza con 100 M. El precio base de cada carta es 2 M y la puja sube en incrementos mínimos de 1 M.
- La identidad, el club, la temporada y la valoración de cada futbolista permanecen ocultos durante la subasta. Usa las pistas visibles de la carta para decidir cuánto ofrecer.
- Si ganas una subasta, la carta se revela y ocupa esa posición de tu plantilla.
- El saldo reservado para completar los puestos vacíos limita cuánto puedes pujar. Así nadie puede gastar todo su presupuesto al principio y quedarse sin opciones para terminar el equipo.
- Si no hay pujas, el juego puede ofrecer un voto unánime para saltar esa carta cuando todavía haya candidatos suficientes. Cuando ya no hay margen, la carta se adjudica para que la ronda avance.
- Reacciones rápidas sirven para comunicarse durante la subasta; no cambian las reglas ni la puntuación.

## Final

Al completar las once posiciones, se comparan los equipos posición por posición. El mejor rating de cada puesto suma un punto; si hay empate, ese punto se reparte. Si el total también empata, decide primero la suma de ratings de toda la plantilla y luego el presupuesto restante.

La ceremonia final presenta el resultado y permite proponer una revancha desde la misma sala.
